# 🧬 遗传学卡方值计算器 (Genetics Chi-Square Calculator)

专为遗传学研究、孟德尔分离比验证（如 3:1、1:1、1:2:1、9:3:3:1）以及卡方适合度检验打造的高精度计算工具。支持输入观测值、期望值和自由度，自动计算实际卡方值、对应 $p=0.05$ 与 $p=0.01$ 的临界表值，并输出严谨的生物学及统计学显著性检验结论。

---

## 🚀 三种使用方式

### 方式一：独立网页版（双击即用，零依赖）
直接在 Mac 终端中运行以下命令或在访达（Finder）中双击打开：
```bash
open index.html
```
- **纯本地运行**：无需启动 R 服务或安装任何依赖，任何浏览器（Safari、Chrome、Edge）秒开。
- **动态交互**：支持孟德尔经典分离比一键预设、即时计算、卡方曲线拒绝域可视化绘制、各表型卡方贡献明细表。

---

### 方式二：R Shiny 交互式 Web 应用
在项目根目录启动专业 R 交互界面：
```bash
Rscript -e "shiny::runApp('.', launch.browser = TRUE)"
```
- 基于 R 语言原生 `pchisq` / `qchisq` 严谨统计计算。
- 提供卡方概率密度曲线、观测值 vs 期望值柱状图对比及各组分项贡献。

---

### 方式三：命令行 / 终端批处理脚本 (`chisq_calculator.R`)

#### 1. 交互式运行：
```bash
./chisq_calculator.R
# 或
Rscript chisq_calculator.R
```
程序将逐步提示输入观测值、期望值（或理论比例）与自由度。

#### 2. 命令行参数化运行（适合嵌入生信分析流程）：
```bash
# 孟德尔 9:3:3:1 验证：输入观测值与期望值
./chisq_calculator.R --obs "315, 108, 101, 32" --exp "312.75, 104.25, 104.25, 34.75" --df 3

# 自动使用理论分离比折算期望值：
./chisq_calculator.R --obs "315, 108, 101, 32" --ratio "9:3:3:1" --df 3

# 孟德尔 1:1 测交验证 (可选开启 Yates 连续性校正 --yates)：
./chisq_calculator.R --obs "85, 75" --exp "80, 80" --df 1 --yates

# 已知卡方值，快速查表判别显著性：
./chisq_calculator.R --chisq 0.47 --df 3
```

## 📊 统计学原理与判定标准

1. **适合度检验统计量计算**：
   $$\chi^2 = \sum_{i=1}^k \frac{(O_i - E_i)^2}{E_i}$$
   *(当 $df = 1$ 且开启 Yates 校正时：$\chi^2_c = \sum \frac{(|O_i - E_i| - 0.5)^2}{E_i}$)*

2. **临界表值**：
   - $\chi^2_{0.05, df}$：$P = 0.05$ 显著性水准对应的临界界值 (`qchisq(0.05, df, lower.tail=FALSE)`)
   - $\chi^2_{0.01, df}$：$P = 0.01$ 极显著性水准对应的临界界值 (`qchisq(0.01, df, lower.tail=FALSE)`)

3. **判定结论体系**：
   | 范围 | 显著性判定 | 原假设 $H_0$ 判定 | 遗传学结论 |
   | :--- | :--- | :--- | :--- |
   | $\chi^2 < \chi^2_{0.05}$ | **差异不显著 (ns, $P > 0.05$)** | 接受 $H_0$ | 观测值符合预期分离比例（理论遗传规律成立） |
   | $\chi^2_{0.05} \le \chi^2 < \chi^2_{0.01}$ | **差异显著 (*, $0.01 < P \le 0.05$)** | 拒绝 $H_0$ | 观测值偏离理论预期，存在5%水平显著差异 |
   | $\chi^2 \ge \chi^2_{0.01}$ | **差异极显著 (**, $P \le 0.01$)** | 极显著拒绝 $H_0$ | 严重偏离理论比例，可能存在致死基因、连锁或强选择压力 |
