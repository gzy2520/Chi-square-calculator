# 🧬 遗传学卡方值计算器 (Genetics Chi-Square Calculator)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![R: >= 4.0](https://img.shields.io/badge/R-%3E%3D4.0-brightgreen.svg)](https://www.r-project.org/)

专为遗传学研究、孟德尔分离比验证、双基因上位/互作分析以及卡方适合度检验打造的高精度开源计算器。

支持自由输入或设置任意理论遗传分离比（如 `9:7` 互补作用、`9:3:4` 隐性上位、`12:3:1` 显性上位、`13:3` 显性抑制、`15:1` 重叠基因、`9:6:1` 积加作用、`2:1` 显性致死、`9:3:3:1`、`3:1` 等），自动计算卡方统计量、精准 P 值、对应 $\alpha=0.05$ 与 $\alpha=0.01$ 的临界分布表值，并输出严谨的生物学显著性结论。

---

## 🌟 核心特性

- **分离比自由定制**：支持直接输入任意冒号、逗号或空格分隔的比例（例如 `9:7`、`13:3`、`1:4:6:4:1`、`9:3:4`），自动按样本总数计算期望值 $E_i = N \times \frac{r_i}{\sum r}$。
- **全套遗传上位与互作预设**：一键填充 13 种常见遗传学比例（互补、上位、抑制、重叠、致死等）。
- **双重临界表值与 P 值**：根据指定或自动推导的自由度 $df$，同步输出 $p=0.05$ 及 $p=0.01$ 临界表值。
- **三种交互形态**：
  1. **独立可视化网页版（双击即用，零依赖）**：[index.html](index.html)
  2. **R Shiny 交互式 Web 应用**：[app.R](app.R)
  3. **R 命令行/脚本工具**：[chisq_calculator.R](chisq_calculator.R)
- **统计学严谨性**：支持 $df = 1$ 时的 Yates 连续性校正，内置 Cochran 期望频数提示。

## 🚀 使用指南

### 1. 独立网页版（最推荐，零依赖）
无需安装任何软件或依赖，直接用任何现代浏览器打开：
```bash
open index.html
```
- 支持快捷点击选择上面任何比例预设。
- 支持自由修改或手动键入任意分离比例（例如输入 `9:7` 或 `1:4:6:4:1`）。
- 实时绘制卡方概率密度曲线、显著性拒绝域、各组离差及贡献率明细表。

### 2. 命令行与生信脚本调用 (`chisq_calculator.R`)
```bash
# 9:7 互补作用检验 (香豌豆花色)
./chisq_calculator.R --obs "188, 140" --ratio "9:7" --df 1

# 9:3:4 隐性上位检验 (家兔毛色)
./chisq_calculator.R --obs "180, 62, 78" --ratio "9:3:4" --df 2

# 孟德尔经典 9:3:3:1 检验
./chisq_calculator.R --obs "315, 108, 101, 32" --ratio "9:3:3:1" --df 3

# 直接输入实际观测与期望数值 (如 1:1 测交，开启 Yates 校正)
./chisq_calculator.R --obs "85, 75" --exp "80, 80" --df 1 --yates

# 交互式引导输入
./chisq_calculator.R
```

### 3. R Shiny 本地交互应用
```bash
Rscript -e "shiny::runApp('.', launch.browser = TRUE)"
```
